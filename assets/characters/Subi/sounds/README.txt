Put Subi's own sound effects in this folder (.wav or .ogg).
Suggested file names:

  select.wav    voice line when Subi is picked in character select
  punch.wav     melee attack (J)
  kick.wav      kick attack
  special.wav   ranged / projectile attack (K)
  block.wav     blocking a hit (L)
  hit.wav       Subi gets hit
  ko.wav        Subi is knocked out
  victory.wav   Subi wins the round
