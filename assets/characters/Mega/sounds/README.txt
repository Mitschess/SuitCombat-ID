Put Mega's own sound effects in this folder (.wav or .ogg).
Suggested file names:

  select.wav    voice line when Mega is picked in character select
  punch.wav     melee attack (J)
  kick.wav      kick attack
  special.wav   ranged / projectile attack (K)
  block.wav     blocking a hit (L)
  hit.wav       Mega gets hit
  ko.wav        Mega is knocked out
  victory.wav   Mega wins the round
