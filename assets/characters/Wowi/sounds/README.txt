Put Wowi's own sound effects in this folder (.wav or .ogg).
Suggested file names:

  select.wav    voice line when Wowi is picked in character select
  punch.wav     melee attack (J)
  kick.wav      kick attack
  special.wav   ranged / projectile attack (K)
  block.wav     blocking a hit (L)
  hit.wav       Wowi gets hit
  ko.wav        Wowi is knocked out
  victory.wav   Wowi wins the round
