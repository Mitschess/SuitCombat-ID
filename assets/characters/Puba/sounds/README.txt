Put Puba's own sound effects in this folder (.wav or .ogg).
Suggested file names:

  select.wav    voice line when Puba is picked in character select
  punch.wav     melee attack (J)
  kick.wav      kick attack
  special.wav   ranged / projectile attack (K)
  block.wav     blocking a hit (L)
  hit.wav       Puba gets hit
  ko.wav        Puba is knocked out
  victory.wav   Puba wins the round
